# Construct an apaTables table spec (render-agnostic IR)

Construct an apaTables table spec (render-agnostic IR)

## Usage

``` r
apa_table_spec(
  body,
  col_labels,
  col_align,
  title = NULL,
  notes = list(),
  number = NA_integer_,
  spanners = list(),
  row_groups = list(),
  landscape = NA,
  meta = list()
)
```
