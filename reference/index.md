# Package index

## Build APA tables

- [`apa.cor.table()`](https://dstanley4.github.io/apaTables/reference/apa.cor.table.md)
  : Create an APA-style correlation table
- [`apa.reg.table()`](https://dstanley4.github.io/apaTables/reference/apa.reg.table.md)
  : Create an APA-style regression table
- [`apa.aov.table()`](https://dstanley4.github.io/apaTables/reference/apa.aov.table.md)
  : Create an APA-style fixed-effects ANOVA table
- [`apa.1way.table()`](https://dstanley4.github.io/apaTables/reference/apa.1way.table.md)
  : Create an APA-style table of means for a one-way design
- [`apa.2way.table()`](https://dstanley4.github.io/apaTables/reference/apa.2way.table.md)
  : Create an APA-style table of means for a two-way design
- [`apa.d.table()`](https://dstanley4.github.io/apaTables/reference/apa.d.table.md)
  : Create an APA-style table of pairwise d-values
- [`apa.afex.table()`](https://dstanley4.github.io/apaTables/reference/apa.afex.table.md)
  : Create an APA-style ANOVA table from afex output

## Use tables in Quarto (apaquarto)

A table goes into a Quarto document one way: build it on one line, then
pass it to the entry point named for the document’s own destination –
apa.quarto.pdf(), apa.quarto.docx(), apa.quarto.html() or
apa.quarto.revealjs() – on the next. The rest of this section sets a
project up and writes the code for you.

- [`apa.quarto.revealjs()`](https://dstanley4.github.io/apaTables/reference/apa.quarto.pdf.md)
  [`apa.quarto.pdf()`](https://dstanley4.github.io/apaTables/reference/apa.quarto.pdf.md)
  [`apa.quarto.docx()`](https://dstanley4.github.io/apaTables/reference/apa.quarto.pdf.md)
  [`apa.quarto.html()`](https://dstanley4.github.io/apaTables/reference/apa.quarto.pdf.md)
  : Display an apaTables table in a Quarto document

- [`apa.quarto.new()`](https://dstanley4.github.io/apaTables/reference/apa.quarto.new.md)
  : Start a new APA manuscript that renders on the first try

- [`apa.quarto.setup()`](https://dstanley4.github.io/apaTables/reference/apa.quarto.setup.md)
  : Install or repair this project's apaquarto extension

- [`apa.quarto.template()`](https://dstanley4.github.io/apaTables/reference/apa.quarto.template.md)
  : Print a ready-to-paste apaquarto chunk for a table

- [`apa.quarto.example()`](https://dstanley4.github.io/apaTables/reference/apa.quarto.example.md)
  : Write two ready-to-render example documents showing every apaTables
  table

- [`apa_caption()`](https://dstanley4.github.io/apaTables/reference/apa_caption.md)
  :

  Caption text for a table (for the apaquarto `tbl-cap` settings line)

- [`apa_note_text()`](https://dstanley4.github.io/apaTables/reference/apa_note_text.md)
  :

  Note text for a table (for the apaquarto `apa-note` settings line)

## Save tables to Word or HTML

The other way out of apaTables: one command writes a table – or several
tables – to a Word (.docx) or HTML file.

- [`apa.save()`](https://dstanley4.github.io/apaTables/reference/apa.save.md)
  : Save apaTables tables to a Word (.docx) or HTML (.html) file
